## 玩法与 API 的分工

知乎 CLI 0.6.0 提供搜索、热榜、按问题取回答摘要、全网搜索及问答模型等能力。本轮使用 `search zhihu` 取得五条来源摘要，模型整理为五类卡，并生成六岛声明式计划。未经来源支撑的内容标为假设；人物卡身份与摘录由真实检索结果约束，不把模型追问显示为作者原话。

来路读经历；此地检查条件；岔路读两岸后做对照；遇见读作者摘要并记录自己的态度；未至检查与实际盲点卡等量的迷雾节点；成形选证据并自己写答案。计划控制提示、追问与材料关系，应用代码控制动作和完成条件，不执行生成代码。

「在线重规划」将收集、存疑/惊讶、对照与岛内选择发送给模型；新计划保存入原世界。它由按钮触发，不是在每次到访时自动调用。成形窗口另有「在线调整整合提示」，结合已选证据和探索历史。
